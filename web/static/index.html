Intercom Key Cloner

Clone intercom / access keys (ACR122U · 13.56 MHz)

How it works: copy an intercom key onto a "magic" blank. Keys with empty sectors (UID only) are copied in full and open the door. Keys with custom sector keys (protected data) cannot be cloned with this reader — you need a Proxmark3. Works only with 13.56 MHz MIFARE Classic; 125 kHz keys (EM-Marine) are invisible to this reader.
